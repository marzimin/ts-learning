## 🐍 Async Pattern Comparison

| Python (asyncio/httpx) | JavaScript (fetch) | Same concept? |
|---|---|---|
| `async def fn():` | `async function fn()` | ✅ |
| `await client.get(url)` | `await fetch(url)` | ✅ |
| `response.json()` | `await response.json()` | ⚠️ JS needs await |
| `try/except` | `try/catch` | ✅ |
| `raise_for_status()` | `if (!response.ok) throw` | similar |
