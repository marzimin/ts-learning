# Phase 1 — Web Fundamentals

Before writing a single line of TypeScript, you need to understand what it builds on top of.
This phase covers the three layers of every webpage — and by extension, every ML frontend you'll build.

---

## The Three Layers (Your Mental Model)

| Layer | Language | Python Analogy |
|---|---|---|
| **Structure** | HTML | Defining a schema / DataFrame columns |
| **Style** | CSS | Formatting output for readability |
| **Behaviour** | JavaScript | The actual logic — your Python scripts |

TypeScript (Phase 2) is simply JavaScript with a strict type system bolted on.
React (Phase 3) is a JavaScript library for building UIs.
Everything traces back to these three layers.

## How to Navigate Each Week

1. Read the week's `README.md` fully before opening any code file
2. Open the starter file — read all comments and `TODO` markers
3. Write your solution
4. Run / preview it (instructions in each README)
5. Fill in `NOTES.md` using the weekly ritual template
6. Use Claude Code Mode 2 to review your work
